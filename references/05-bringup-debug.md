# G7–G8：上电、基础固件、功能验证和排故

## 每个测量请求的完整格式

一次请求一个有区分力的测量，或一组同状态测量。写明：

```text
板号/版本：...
连接状态：断开哪些电源/USB/调试器；开关和按键状态
仪表：直流电压/电阻/二极管/示波器；量程如需要
黑表笔：明确的GND测试点或连接器脚号
红表笔：位号-脚号（网名），附可识别方向或图
预期范围：来自电路和器件规格，不是脱离负载的固定答案
结果格式：数值+单位；若变化，给范围/时间趋势
异常分支：哪些结果先断电，哪些结果进入下一项
```

器件焊盘被遮住时，先查同网外露电阻、电容、接口或过孔。不得反复要求用户探不到的IC底部焊盘；“同网点”应由工程确认。只有两个测点一直接近0Ω等关键异常才升级到隔离/拆件，避免无目的返修。

## 断电检查

1. 拔除电池、USB和可能供电的转接器；用电压挡确认待测轨基本放电后再测电阻/二极管。
2. 记录表笔短接阻值，完全冷却后测电源/GND、复位/启动脚、差分对、相邻可疑网。万用表蜂鸣阈值不是短路定义。
3. 电容充电、保护二极管和芯片内部通路会造成阻值变化和正反向差异。不能把在路电阻直接用于估算芯片工作电流。
4. 两路分别经上拉电阻到同一电源，网间可能读到近似串联阻值，不等于锡桥。低阻要与理论、空板、邻板和表笔电阻比较。
5. 电池接口用实际电压/针序验证；不能只靠线色和塑料缺口。不要在带电电池两端使用电阻挡。

## 限流上电

输入接到设计的电源入口。先在确认有效的标称输入下做短路排查，初始限流根据预计启动需求和受测回路制定，记录预期；并非所有板固定0.05A或0.5A。

若持续CC、电压塌陷或器件快速异常升温，停止持续通电，定位原因。通过初查后，功能测试允许达到已评估的启动/峰值电流；限流太小造成的重启不能直接判电路错误。

同步记录电源实际电压、电流、CV/CC、稳压器输出、负载附近输出和复位状态。显示0A可能低于仪器分辨率，也可能未启动，不能单独定性。

逐个检查：输入→各电源轨→EN/RESET→启动脚→时钟/ROM日志（适用时）。判断“温热”只作描述；额定温度/功耗验证需要合适测温和工况，不能靠手指长期按住就判合格。

## 下载恢复与通信识别

- 先明确正在看的是原生USB设备，还是外接USB-UART转换器。记录 VID/PID、序列号、端口及线缆连接；端口号不能从另一个电脑或旧会话固定套用。
- 确认数据线具备数据功能、主板实际供电、逻辑电平和公共地。多电源并接按电源状态表处理。
- 检查转换器模式及TX空闲电压，必要时查RX偏置和规格；不能只测VCC，也不能一概保证输入脚绝无回灌。外部高电平超过目标允许值时先修正电平匹配。
- UART可先对转换器做合适的回环测试（断开目标板），再接目标TX/RX；测试跳帽在正式接线前移除，RTS/DTR仅按明确复位电路使用。
- 按具体芯片ROM文档执行BOOT/RESET顺序，读取身份和Flash信息，保存握手结果。
- 刷写前备份需要保留的配置/模板，明确仅应用分区还是全片。不得把擦除全部校准/用户数据当例行排故步骤。
- 烧录成功要包含工具退出码和哈希/校验结果，再检查运行日志；转换器LED、单次识别、应用LED都不能替代。
- 设备描述符失败/代码43不能直接归因于“空片”“没有驱动”或“USB阻抗”。先分层排查供电、复位、启动、物理连接和软件状态。

## 最小诊断固件

记录芯片目标、SDK版本、引脚表和固件哈希。最小程序按模块启用，不同时打开全部外设掩盖来源。

1. 启动信息：版本、复位原因、关键配置、内存或故障计数（适用时）。
2. GPIO：LED可控亮灭；按键按下/释放、有效电平、消抖；避免驱动与电路冲突。
3. 总线：ACK/身份寄存器、配置写入回读、原始数据、错误计数。
4. 传感器：静置/方向变化、多轴响应、厂家规定的自检；记录量程、ODR、等待和判据。自检不是完整精度校准。
5. 中断：输出模式、路由寄存器、接收GPIO、脉宽/电平、清除机制分别验证。内部上下拉可帮助判断悬空，但不能据此保证中间整段都连通。
6. 通信：持续双向数据、长度/校验、不同包边界、重连；遇到固定包长相关故障时考虑协议/驱动/缓冲实现，不一律返修PCB。
7. 电源：最大/标称/最低有效输入、对应负载与无线突发，测负载附近电压；有示波器才报告纹波/瞬态，注明探头与接法。
8. 无线：扫描、连接、数据交换是不同层次。接收端确认和错误率比“看到了广播名”更有力。
9. 电池/关机：实际电池、拔掉外部数据/调试线后的独立运行、关机电流、重启、低电量策略和需要的续航；秒级日志不能证明多小时续航。

次数、时间、负载、电压和容差在测试前按需求指定。并非每个项目都需要做EMC/眼图等全部专门测试，但不能在没做时宣称通过。

## 实板故障决策表

| 现象 | 先做的区分测试 | 避免的跳跃结论 |
|---|---|---|
| 电源轨低阻/发热 | 放电冷却、表笔基线、对照板、分段隔离 | 在路1kΩ等于芯片漏电；温热必坏 |
| RESET一直低 | 按键拆离后是否仍低、RC、电阻网络、同网焊接 | 按钮肯定坏，或重刷固件可修 |
| 启动脚相互低阻 | 正确焊盘配对、两路上拉路径、裸板与装配后对照 | 不为OL就是短路 |
| USB反复连接 | RESET按住/松开时差异、供电、ROM模式、已知线缆 | 立即更换ESD保护器件 |
| 串口无输出 | 转换器独立识别/回环、共地、交叉接线、启动状态 | RX指示灯灭就等于芯片坏 |
| I²C正常但无中断 | 寄存器、模式、GPIO、外露测点与上下拉 | 传感器完全坏，或中断已经通过 |
| 只有特定USB包长失败 | 协议边界、ZLP/缓存/超时和软件实现 | 直接等同阻抗失败 |

拆件前保存故障状态。拆下后分别测PCB和器件可以缩小范围；两者都恢复不短支持装配问题，但不能证明器件所有功能完好。返修后重跑受影响功能和邻近网络，不把一次返修成功推广到所有板。

若用户接受禁用中断、改轮询等方案，更新功能范围、固件和功耗说明，保留未解决原因；只有当前轮询路径可标通过，原中断和休眠仍未验证。
